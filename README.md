# Sistema de Figuras 3D — Fase 4 UNAD

## Descripción
Aplicación en Python con interfaz gráfica Tkinter que calcula volúmenes y áreas superficiales de figuras geométricas tridimensionales, implementando manejo robusto de excepciones.

## Características
- ✅ Herencia y polimorfismo en clases (Cubo, Esfera, Cilindro)
- ✅ Excepciones personalizadas: `DimensionInvalidaError`, `EscalaInvalidaError`
- ✅ Bloques `try/except/else/finally` con encadenamiento de excepciones
- ✅ Sistema de registro de eventos en archivo `registro.log`
- ✅ Validación de entradas del usuario
- ✅ Interfaz gráfica en inglés con Tkinter

## Estructura del proyecto
- `figuras_3d_fase4.py` — Código fuente completo del programa
- `registro.log` — Historial de eventos y errores generado por las simulaciones
- `evidencia_ejecucion.png` — Captura de pantalla de la interfaz funcionando
- `README.md` — Este archivo con la documentación del proyecto
